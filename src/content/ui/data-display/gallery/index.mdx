  - question: My images have different sizes. How do I keep the grid even?

A gallery shows a set of images as an even grid of thumbnails. It is a plain list
of `<img>` elements laid out with the `auto-grid` utility, so it reflows by the
available width without media queries, and the lightbox variant opens each image
in a native `<dialog>` with focus handling and a backdrop for free.

## Usage

- Wrap the images in a `<ul role="list" class="auto-grid gap">` and set the
  minimum thumbnail width with `--max-col-size`.
- Give every `<img>` its `width` and `height`, so the browser reserves the space
  before it loads, and `loading="lazy"` so images below the fold wait.
- When the images differ in size, add an `aspect-ratio` and `object-cover` so they
  crop to the same shape.

## Lightbox

Wrap each thumbnail in a button that opens a [modal](/ui/overlays/modal/) with the
larger image and a caption. The `--btn-px`, `--btn-py`, and `--btn-border-width`
variables on the list strip the button padding and border, so only the image
shows. Every dialog needs its own `id`, matched by the thumbnail's `commandfor`.

## Anatomy

| Part                                | Responsibility                                     |
| ----------------------------------- | -------------------------------------------------- |
| `<ul class="auto-grid gap">`        | The grid, reflowing by available width.            |
| `<img>`                             | A thumbnail, with its own `alt`, width, and height. |
| `<button command="show-modal">`     | Lightbox only. Opens the dialog for its image.     |
| `<dialog>` with `<figure>`          | Lightbox only. The large image and its caption.    |

## Accessibility

- Write an `alt` that describes each image. In the lightbox, the thumbnail's `alt`
  also names its button, so it tells the reader what opens.
- Label each dialog with `aria-labelledby` pointing at its caption.
- The dialog moves focus in when it opens and returns it to the thumbnail when it
  closes. Escape closes it, and so does a click on the backdrop.
- Give the icon only close button an `aria-label`.
