Buttons do not have to be rounded rectangles. The CSS `corner-shape` property changes
how each corner inside the border radius is drawn: a smooth squircle, a straight
bevel, a square notch, or an inward scoop. It only changes the shape, so the border,
background, focus ring, and hover styles of the [Button](/ui/actions/button/) still
apply, and browsers without support simply show normal rounded corners.

## Usage

- Set `--btn-radius` to the size of the corner, then `corner-shape` to its shape. The
  radius decides how big the corner is, the shape decides how it is drawn.
- The keywords are `round` (the default), `squircle`, `bevel`, `notch`, `scoop`, and
  `square`.
- Like `border-radius`, `corner-shape` takes up to four values, one per corner, in the
  same order: top left, top right, bottom right, bottom left.
- Shapes that cut into the button need a bit more padding, set with `--btn-px`.

## Anatomy

| Part            | Responsibility                                                  |
| --------------- | --------------------------------------------------------------- |
| `--btn-radius`  | How big each corner is. Without it there is nothing to shape.   |
| `corner-shape`  | How each corner is drawn, from a smooth curve to a sharp cut.   |
| `--btn-px`      | Extra padding to keep the label clear of deep cuts.             |

## Accessibility

- The shape is purely visual. The element stays a native button with its role, label,
  and keyboard behavior.
- Keep shapes consistent per action type, so users learn what a shape means. A
  different shape for every button makes a page harder to scan.
- An arrow shaped button is still read by its text. Write "Next" or "Back" in the
  label, do not rely on the shape to point the way.

## Variants

### Primary

The shapes work on any button style, including a filled primary button.

<ComponentPreview center code={examplePrimary} />

### Mixed corners

Give each corner its own shape and radius to make arrows, tags, and tabs. The arrows
use a vertical radius of `50%`, so the bevels meet in a point, and a fixed horizontal
radius for the depth of that point. Pad the pointed side by a bit more than that depth,
so the label stays clear of it.

<ComponentPreview center code={exampleMixed} />

### Superellipse

`superellipse()` takes a number for a shape between the keywords. Negative values curve
inward, `0` is a straight bevel, `1` is round, and higher values get closer to a square
corner.
