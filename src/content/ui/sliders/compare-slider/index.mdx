A compare slider stacks two images of the same scene and lets the reader drag a
divider across them, to show a before and after or two versions side by side. The
control is a native `<input type="range">` laid over the images, so it is focusable,
works with the arrow keys and touch, and announces its value without any ARIA. The
range position is read in CSS, so the split follows the thumb without JavaScript.

## Usage

1. Wrap two images and a range input in an element with `stack`, so they share one
   grid cell. The first image is the base, the second is clipped by the slider.
2. Keep both images the same size and aspect ratio, so the two halves line up.
3. Give the range `min="0"`, `max="100"`, and a starting `value`, and name it with a
   visually hidden `<label>`.
4. Add the `<style>` block. It moves the `--range-value` from form-extend up to the
   wrapper with `timeline-scope`, so the second image, the divider line, and the
   percentage label can all read it. The `::-moz-range-thumb` rule names the same
   timeline in Firefox, which form-extend only sets on the WebKit thumb.

Restyle the handle with `--compare-handle` and the divider with `--compare-line`.
`--compare-color` sets the color of both. Keep the range thumb thin: form-extend
measures its position including its width, and a wide thumb makes `--range-value`
drift from the real value towards the ends.

## Anatomy

| Part                       | Responsibility                                                         |
| -------------------------- | ---------------------------------------------------------------------- |
| `.compare-slider.stack`    | Layers every child in one grid cell and shares `--range-value`.         |
| First `<img>`              | The base image, visible on the start side of the divider.              |
| Second `<img>`             | The compared image, clipped from the start edge up to the divider.     |
| `::before`                 | The divider line that follows the thumb.                               |
| `::after`                  | The round handle, drawn at the split.                                  |
| `<input type=range>`       | The control, stretched over the images with a transparent track and thumb. |
| `.compare-slider-value`    | The visual percentage, written with a CSS counter.                      |

## Accessibility

- The range input is the only control, so it gets the keyboard behavior for free:
  the arrow keys move the divider, and <kbd>Home</kbd> and <kbd>End</kbd> jump to
  either side.
- Name the range by what it changes, such as "Amount of the color photo shown", not
  "Slider".
- Give both images an `alt` that says what is different, so a screen reader user
  knows what is being compared without seeing it.
- The percentage label is `aria-hidden`, since the range already announces its
  value.

## Browser support

The CSS only version relies on scroll-driven animations and `timeline-scope`. In a
browser without them the split stays at the starting `--range-value`. Add this
script once per page to move the split on input there. It only runs where
`timeline-scope` is missing.
