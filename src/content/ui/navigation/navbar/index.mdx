A navbar is the header at the top of a site, with the brand on one side and the
main navigation links on the other. On small screens the links move into a drawer
behind a menu button. The drawer is the native `<dialog>` from the
[Offcanvas](/ui/overlays/offcanvas/), opened with an invoker command, so the mobile
menu traps focus, closes on Escape, and returns focus to the button, all without
JavaScript.

## Preview

The links show inline from the `md` breakpoint up. Make the window narrow to see the
menu button and open the drawer.

## Usage

- Wrap the bar in a `<header>` with `flex align gap`, which keeps the brand at the
  start and pushes the navigation to the end.
- Put the inline links in a `<nav aria-label="Main">` with a `<ul>`, each link an
  `<a class="btn">`. Hide this nav on small screens with `hidden md:block`.
- Mark the current page `aria-current="page"`. Fylgja's button active style
  highlights it, so no extra class is needed.
- Add a menu `<button>` with `md:hidden`, `commandfor`, and `command="show-modal"`
  that opens a `<dialog class="offcanvas">` holding the same links.
- Give the drawer `closedby="any"` and a close button, so Escape, a backdrop click,
  and the button all dismiss it.

## Anatomy

| Part                              | Responsibility                                                |
| --------------------------------- | ------------------------------------------------------------- |
| `<header>`                        | The bar. Lays out the brand, links, and menu button.          |
| Brand `<a href="/">`              | Links home. Text or a logo with an accessible name.           |
| `<nav aria-label="Main">`         | The inline links, shown from the `md` breakpoint up.          |
| Menu `<button command>`           | Opens the drawer on small screens, hidden from `md` up.       |
| `<dialog class="offcanvas">`      | The drawer with the same links, in the top layer.             |

## Accessibility

- Both navs are labeled "Main", and only one is exposed at a time, so a screen
  reader always finds one main navigation landmark.
- `aria-current="page"` marks the current page in both lists.
- The icon only menu and close buttons need an `aria-label`.
- Opened as a modal, the drawer traps focus and makes the page inert, and focus
  returns to the menu button when it closes.

## Variants

### Always collapsed

For a site with many sections, or a header that is short on room, skip the inline
links and always use the menu button and drawer.
