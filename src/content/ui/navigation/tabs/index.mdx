Tabs show one of several related panels in the same space, with a strip of buttons
to switch between them. HTML has no tabs element, so the strip is a row of buttons
in a `role="tablist"`, and a small `<tab-group>` custom element handles selection
and keyboard navigation. On narrow screens the strip scrolls instead of wrapping.

## Usage

- Wrap the strip and panels in `<tab-group>`, and load the script once per page.
- Each tab is a `<button role="tab">` with an `id` and `aria-controls` pointing at its
  panel. Render the selected state in the markup: `aria-selected="true"` on the first
  tab, `aria-selected="false"` and `tabindex="-1"` on the rest.
- Each panel is a `role="tabpanel"` with `aria-labelledby` pointing back at its tab.
  Add `hidden` to every panel except the selected one.
- `scroll-x` lets the strip scroll when the tabs do not fit, `scroll-mask` fades the
  overflowing edge, and `flex-none` keeps each tab from shrinking. When there are
  more tabs than fit, the strip scrolls sideways instead of wrapping onto a second
  row, on mobile and desktop alike.
- The `tabs` class draws a line under the whole strip and gives the selected tab a
  brand colored bottom border. It only sets base button variables, so the tabs keep
  their hover and focus styles.

The Alpine tab shows the same component with `x-data` instead of a custom element.

## Anatomy

| Part                    | Responsibility                                                   |
| ----------------------- | ---------------------------------------------------------------- |
| `<tab-group>`           | Listens for clicks and keys, and switches the selected tab.      |
| `role="tablist"`        | The scrollable strip of tabs, named with `aria-label`.           |
| `<button role="tab">`   | One tab. `aria-selected` marks the active one.                   |
| `role="tabpanel"`       | The content for one tab, hidden unless its tab is selected.      |

## Accessibility

- No native element carries the tab roles, so this is the one place where `role` is
  the right tool. Screen readers announce each tab with its position, such as "tab 1
  of 3", and whether it is selected.
- Only the selected tab is in the Tab order. The Left and Right arrow keys (Up and
  Down for vertical tabs) move between tabs, Home and End jump to the first and
  last, and Tab moves on into the panel.
- Panels have `tabindex="0"`, so keyboard users can reach a panel that holds no
  focusable content.
- Name the tablist with `aria-label` or `aria-labelledby`, and keep the tab labels
  short and unique.

## Variants

### Vertical tabs

Add `aria-orientation="vertical"` to the tablist and stack it with `flex-col` next
to the panels. The line moves to the side of the strip, and the script switches to
the Up and Down arrow keys. Vertical tabs suit settings pages with more tabs than fit
in a row.
