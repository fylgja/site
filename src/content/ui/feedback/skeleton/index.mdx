A skeleton is a set of gray shapes that stand in for content while it loads. It
mirrors the layout of what is coming (an image, a title, a few lines of text), so
the page does not jump once the real content arrives, and a soft shimmer shows
that something is happening.

## Usage

- Mark the region that is loading with `aria-busy="true"`, and put a short
  `sr-only` line inside it that says what is loading.
- Wrap the shapes in an element with `aria-hidden="true"`, and size each
  `.skeleton` with the `--size-y` and `--size-x` variables so it matches the
  content it replaces.
- When the content is ready, replace the shapes and set `aria-busy` to `false`.
- The `.skeleton` rule fills the shape and adds the shimmer only when the reader
  has not asked for reduced motion. Its border radius is wrapped in `:where()`, so
  utilities like `round` still win.

## Anatomy

| Part                      | Responsibility                                          |
| ------------------------- | ------------------------------------------------------- |
| `[aria-busy="true"]`      | The region that is loading.                             |
| `.sr-only` text           | Tells screen reader users what is loading.              |
| `[aria-hidden="true"]`    | Hides the placeholder shapes from assistive tech.       |
| `.skeleton`               | One placeholder shape, sized with `--size-y` and `--size-x`. |

## Accessibility

- The shapes are hidden with `aria-hidden`, and the `sr-only` text is the only
  thing a screen reader finds while the region loads.
- `aria-busy` asks assistive tech to hold off on the region until it is filled.
- The shimmer respects `prefers-reduced-motion` and does not run for readers who
  turn motion off.
- Never put focusable elements inside the skeleton. There is nothing to act on
  until the content arrives.
