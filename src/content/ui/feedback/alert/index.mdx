An alert is a small message in the top corner of the viewport that tells the user
something went wrong or needs their attention. It uses the [Toast](/ui/feedback/toast/)
style, but floats above the page and stays until the user dismisses it. It is built on a `popover="manual"`, so the browser puts it in the
top layer and invoker commands show and hide it without JavaScript.

## Usage

- The alert is a `<div popover="manual" role="alert">` with the `toast alert`
  classes. Set `data-type="error"`, `"warning"`, or `"info"` for its color, the same
  as a toast.
- A button with `commandfor` and `command="show-popover"` shows it. In a real app you
  can also call `showPopover()` from a script, such as after a request fails.
- The dismiss button inside it uses `command="hide-popover"`. A manual popover does not
  close on Escape or an outside click, so always include one.
- Place it with the `fixed` utility and its inset variables. `--inset-t` and
  `--inset-e` put it in the top right corner. Swap in `--inset-s` for the top left.
- The small `.alert` rule caps the width, drops the popover centering, keeps the
  dismiss button at the end, and hides the alert while it is closed, since `.toast`
  sets its own `display` and would otherwise override the hidden popover.

## Anatomy

| Part                              | Responsibility                                                |
| --------------------------------- | ------------------------------------------------------------- |
| `<div popover="manual">`          | The alert. Top layer, fixed to the viewport, hidden until shown. |
| `.toast`                          | The message style: border, shadow, and the `data-type` colors. |
| Icon and text                     | The message itself, with an icon that matches the type.       |
| Dismiss `<button>`                | Hides the alert with `command="hide-popover"`.                |

## Accessibility

- `role="alert"` makes screen readers announce the message right away. Keep it for
  problems, and use a toast with `role="status"` for routine confirmations.
- The dismiss button is icon only, so it needs an `aria-label`.
- Focus stays where it was when the alert opens. Keep the message short and make sure
  nothing in it is required to continue, since keyboard users have to Tab to reach it.
- Do not rely on the accent color alone. Pair the type with a matching icon and clear
  wording.

## Variants

### Warning

Use `data-type="warning"` for a problem that does not stop the user, such as losing the
connection.
