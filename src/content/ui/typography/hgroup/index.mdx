faq:
  - question: Why an hgroup and not a div?
    answer: HTML defines the paragraphs in an hgroup as part of the heading, which a div
      cannot express. The subtitle and eyebrow are not headings of their own, so they
      stay out of the page outline. Screen readers announce little extra for it, so the
      win is mostly in clean, meaningful markup.
  - question: Should the subtitle be a second heading?
    answer: No. A subtitle is not a new section, so an h3 below an h2 would add a false
      level to the outline. Use a paragraph inside the hgroup.
  - question: How does the CSS tell the eyebrow and the subtitle apart?
    answer: By position. A paragraph directly before the heading is the eyebrow, and a
      paragraph after the heading is the subtitle, so the markup needs no classes.

A heading group pairs a heading with a short eyebrow above it, a subtitle below it,
or both. It is built on the native `<hgroup>`, which keeps the extra lines tied to
the heading without adding them to the page outline.

## Usage

- Wrap one heading and its paragraphs in an `<hgroup>`. Base already removes the
  margins between them.
- A `<p>` before the heading becomes the eyebrow, a small uppercase line in the brand
  color.
- A `<p>` after the heading becomes the subtitle, in a larger and muted text.
- The CSS selects the parts by their position, so the markup stays classless.

## Anatomy

| Part                 | Responsibility                                                   |
| -------------------- | ---------------------------------------------------------------- |
| `<hgroup>`           | Groups the heading with its eyebrow and subtitle.                |
| `<p>` before heading | The eyebrow. A short label for the section, such as a category.  |
| `<h1>` to `<h6>`     | The heading itself, and the only part in the page outline.       |
| `<p>` after heading  | The subtitle. One sentence that expands on the heading.          |

## Accessibility

- Only the heading appears in the outline and in a screen reader's list of headings.
  The paragraphs are read as normal text.
- Screen readers read the hgroup in source order, so the eyebrow is announced before
  the heading. Keep it short, so it does not delay the heading.
- Pick the heading level for its place in the page, not for its size.
