A heading underline adds a short brand colored bar below a heading, a common accent
for section titles. The bar is an `::after` pseudo element, so the markup stays a
single heading with one class.

## Usage

- Add the `heading-underline` class to any heading.
- Change the bar with `--underline-size` for the width, `--underline-thickness` for
  the height, `--underline-gap` for the space above it, and `--underline-color`.
- Add `text-center` to center both the heading and the bar.

## Anatomy

| Part                  | Responsibility                                          |
| --------------------- | ------------------------------------------------------- |
| `.heading-underline`  | The heading. Holds the variables for the bar.           |
| `::after`             | The bar, a block below the text with rounded ends.      |

## Accessibility

- The bar is decorative and has no content, so it is not announced.
- Do not rely on the bar to mark a heading. Use a real heading element at the right
  level, so it appears in the outline.
