An inline footer is the smallest site footer: the copyright and a few links on one
row, with a thin border above it. It suits pages that need little more than the
legal links, and it is the same row the [Classic Footer](/ui/layout/classic-footer/)
and [Brand Footer](/ui/layout/brand-footer/) use as their subfooter.

## Usage

- Use a `<footer>` with `flex-wrap gap align`. The default `--align` of `.align`
  spaces its children apart, so the copyright sits at the start and the links at
  the end.
- `flow-none` clears the default margin on the paragraph, so the row height comes
  from `--py` alone.
- Draw the line with `border-block-start-width` and a border color mixed from
  `--root-bg` and `--root-fg`, so it follows light and dark mode.
- Put the links in a `<nav>` with a `<ul>`. Base already strips the list styles
  inside a nav, and `flex-wrap gap` lays the items out in a row.
- Wrap the copyright in `<small>`, the element for fine print.

## Anatomy

| Part              | Responsibility                                                  |
| ----------------- | --------------------------------------------------------------- |
| `<footer>`        | The row, its top border, and the spacing between the two parts. |
| `<small>`         | The copyright line, set as fine print.                          |
| `<nav>`           | The link list, named with `aria-label`.                         |

## Accessibility

- A `<footer>` that is a direct child of `<body>` is exposed as the
  `contentinfo` landmark, so screen reader users can jump straight to it.
- Name the nav with `aria-label` (here "Legal") so it is not confused with the
  main navigation.
- Keep the border color for decoration only. The links and copyright must reach
  enough contrast against the page on their own.
