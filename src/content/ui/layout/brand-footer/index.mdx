A brand footer gives the logo and a short tagline a wide column of their own, and
pushes the link groups to the right. Below sits the same subfooter as the
[Classic Footer](/ui/layout/classic-footer/), so the copyright and social icons
stay in the same place across the footer family.

## Usage

- The `<footer>` uses `divide-y` with a border color and a `--flow`, the same as the
  [Classic Footer](/ui/layout/classic-footer/), to draw the line above the subfooter.
- The top part is a `grid-cols` container with `--md_grid-cols` set to 5. The
  branding takes two columns with `--md_col`, and the `<nav>` takes the remaining
  three.
- The nav is a `grid-cols` grid itself, with a column per link group from the md
  breakpoint up and two columns below it.
- The logo is a link home with a `lead` class for the larger, bold name. The icon is
  colored with `--brand` and hidden from assistive technology, since the name is
  already the link text.
- The subfooter is the same row as the [Inline Footer](/ui/layout/inline-footer/),
  with icon links for the social profiles.

## Anatomy

| Part               | Responsibility                                                   |
| ------------------ | ---------------------------------------------------------------- |
| `<footer>`         | The container, and through `divide-y` the subfooter border.      |
| Branding column    | The logo link and the tagline, spanning two of five columns.     |
| Footer `<nav>`     | The link groups, spanning the remaining three columns.           |
| Subfooter          | The copyright and the social nav.                                |

## Accessibility

- A `<footer>` that is a direct child of `<body>` is the `contentinfo` landmark.
- Label each nav ("Footer", "Social") so it is not confused with the main
  navigation.
- The logo link reads as the brand name. Keep the icon `aria-hidden` so it does not
  add a second, empty name.
- Every social link needs an accessible name in `aria-label`, with the icon hidden.
