A classic footer groups the site's secondary links into titled columns, with a
subfooter below for the copyright and social links. The subfooter is the same row
as the [Inline Footer](/ui/layout/inline-footer/), with icon links in place of the
text links.

## Usage

- Give the `<footer>` the `divide-y` utility with a border color and a `--flow`.
  That draws the line above the subfooter and spaces it, with no extra rule.
- The menu is one `<nav>` with `grid-cols`. `--grid-cols` sets the columns on small
  screens and `--md_grid-cols` from the md breakpoint up.
- Each group is a heading and a `<ul>` wrapped in a `flow` container, so the title
  has no top margin and the columns line up. `--list-flow` on the list adds back the
  space between links that base removes inside a nav.
- The subfooter uses `flex-wrap gap align`, so the copyright sits at the start and
  the social links at the end, and the row wraps on narrow screens.
- Social links are [icon](/ui/actions/icon-button/) links. Each `<svg>` is
  `aria-hidden` and the link gets its name from `aria-label`.

## Anatomy

| Part           | Responsibility                                                     |
| -------------- | ------------------------------------------------------------------ |
| `<footer>`     | The container, and through `divide-y` the subfooter border.        |
| Footer `<nav>` | The grid of link groups.                                           |
| Group          | A heading and its list of links.                                   |
| Subfooter      | The copyright and the social nav, laid out like the inline footer. |
| Social `<nav>` | The icon links, named with `aria-label`.                           |

## Accessibility

- A `<footer>` that is a direct child of `<body>` is the `contentinfo` landmark.
- Label each nav ("Footer", "Social") so it is not confused with the main
  navigation.
- Every icon link needs an accessible name. Put it in `aria-label` and hide the
  icon with `aria-hidden="true"`.
- The icons are 24 pixels square, which meets the WCAG 2.2 minimum target size.
  Keep the gap between them so they are not tapped by mistake.
